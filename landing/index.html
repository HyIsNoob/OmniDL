TECHNICAL QUESTIONS

Frequently Asked Questions

Is OmniDL really 100% free and open-source?
Yes. OmniDL is licensed under the permissive MIT License. There are no paid tiers, no subscription locks, and no advertisements. You can inspect and build the complete source code from GitHub.
How does OmniDL merge 4K video and audio?
YouTube delivers 1080p, 2K, 4K, and 8K videos as separate video and audio DASH streams. OmniDL bundles customized FFmpeg binaries to merge the video track (AV1/VP9/H264) and audio track (Opus/AAC) into a pristine, fully compatible MP4 file automatically.
Does TikTok download with or without watermark?
OmniDL downloads the original raw 1080x1920 video stream without the animated TikTok watermark. It also allows you to extract the original audio track in one click.
How do I update the download engine if a website changes?
OmniDL automatically checks for the latest nightly extractor engine from yt-dlp-nightly-builds. You can also click Update yt-dlp in the app's Options tab at any time to grab the latest daily bug fixes.
Where are downloaded files saved?
By default, files are saved to your system's standard Downloads directory. You can customize the download location per job or change the default path in the app settings.
